
## [v1.0.14] - 2026-11-17

### 新增
- 常用语不翻译：整条消息只由寒暄、应答、笑之类的常用语组成时（如 hi、ty、lol、ok bye、hahaha、good night）不调用接口。内置一份默认名单，可在"过滤规则"里增删或恢复默认；只看整条消息，"lol where are you from?" 这类仍会翻译
- 系统通知不翻译（默认开启）：客户端生成的 xxx is online / is offline、进入/离开区域或聊天范围、正在输入等通知不再调用接口，支持英、中、日、德、法、西、葡客户端；名字以代词开头的正常句子（如 my boyfriend is offline）仍会翻译

### 变更
- 检查更新、教程链接改为新仓库 ballard-sketch/SL-AI-Translator；新仓库暂无 Gitee 镜像，Gitee 检查先关闭

## [v1.0.13] - 2026-11-17

### 新增
- 不用翻译的人名单（按账号保存）：名单里的人消息照常显示，但不自动调用接口，节省 Token。可在设置的"过滤规则"里填写，或点消息气泡上的人像按钮一键加入/移出；显示名、用户名都能匹配，气泡旁会标"不翻译"，需要时仍可点"重新翻译"手动翻译

## [v1.0.12] - 2026-11-17

### 新增
- 底部输入栏默认为"翻译我的话"：输入母语，回车后按对方最近的用语译成对方语言并自动复制；可切换到"问 AI"模式
- 语气选项：自然 / 随意 / 友好 / 礼貌 / 调情 / 角色扮演 / 简短，按频道记忆；设置中可改新频道的默认语气
- 目标语言可选"自动（跟随对方）"或手动指定，按频道记忆
- 回译：译文下方显示其大意，便于核对（与翻译同一次请求完成，可在设置中关闭）
- 译文超过 SL 单条 1023 字节时提示
- AI 建议回复改为逐条列出，每条附母语意思，点击即复制
- 消息气泡新增"重新翻译"按钮；翻译失败时在气泡内显示原因
- 对方消息已是目标语言（或只有表情/数字）时不再调用接口
- 跳过翻译的判断支持更多语言：除中日韩外，印尼语/马来语、英语、西语、葡语、法语、德语、越南语、菲律宾语等按常用词判断，俄语、泰语、阿拉伯语等按文字判断；拿不准时照常翻译
- 接收语言改为下拉选择（含印尼语、马来语、越南语、泰语等），列表外的语言可选"其他"手动填写，认不出的语言名会提示
- 输入栏显示"Enter 发送 · Shift+Enter 换行"提示，"问 AI"模式的占位符也加上了换行说明
- 术语表（按账号保存）：每行一个词表示保持原样不翻译；`A = B` 表示 A 固定译为 B、B 固定译为 A。只把当前消息里出现的词条发给模型，收发和建议回复都生效
- 全局快捷键（默认 Ctrl+Alt+T，设置中可录制修改或关闭）：从最小化或托盘状态唤出窗口并聚焦输入框；注册失败时提示可能被占用

### 修复
- 手动换行的多行消息只翻译第一行、后续行丢失：日志续行现在拼回同一条消息；HUD 类首行为空的消息也能正确解析
- 读到写了一半的日志行时内容丢失：只处理到最后一个完整换行，剩余部分下次再读
- 发送者为 `[secondlife:///app/agent/... 名字]` 链接格式时显示整串链接；带链接的 /me 动作消息被丢弃
- 请求卡住时 AI 建议回复框无法关闭：所有请求可取消，30 秒无响应自动超时，关闭按钮始终可见
- 问 AI 结果在返回过程中点"清除"后又重新出现
- API Key 提示条、设置页错误提示无法关闭；设置面板新增关闭按钮
- 按 Esc 从最上层开始逐层关闭弹框和设置面板
- 流式响应中一行数据被拆进两个网络包时丢字
- "自己发的消息"判断改为精确匹配账号名，不再误伤名字相近的其他人
- 多行消息在气泡里保留换行
- 设置改动后自动保存，不再需要手动点"保存"；之前改了术语表/白名单后直接从托盘退出会丢失
- 监听中切换账号仍在监听旧账号目录、显示旧账号聊天记录：现在会切到新账号目录并载入其聊天记录，旧账号未完成的请求一并取消
- 中文输入法组字时按回车（确认字母/候选）会误发送
- 停止后立刻重新开始监听，旧监听线程未退出导致消息重复
- 翻历史记录时一有新消息就强制滚到底部的问题：引入 `isNearBottom()` 检测，仅当用户滚动位置距底部 ≤100px 时才随新消息自动滚底；切换 Tab 和首次加载仍然强制滚到底部
- AI 建议回复气泡无法关闭的问题：展开区加入关闭（×）按钮，点击后销毁对应回复内容
- AI 建议回复因分页加载导致索引漂移、气泡错误吸附到其他消息的问题：改用 `time+sender` 组合字符串作为稳定 key，彻底消除相对索引依赖

## [v1.0.11] - 2026-04-14

### 新增
- 附近频道白名单：启用后仅翻译白名单内用户消息，私聊不受影响
- 关键词屏蔽：消息含指定词时跳过翻译（适用于系统通知过滤）
- 设置面板重构为手风琴分组（连接、API、翻译参数、过滤规则、界面外观），大幅提升可读性
- 设置面板以 position:absolute 全屏覆盖聊天区，视觉清晰无重叠

### 修复
- 关键词/用户名输入框无法输入空格的问题
- 关键词/用户名输入框回车无法换行的问题
- UI Language 切换无响应的问题（由手风琴标题中的脆弱 .split() 表达式导致）
- 关闭设置页后底部输入框浮到顶部的 flex 布局 bug
- App.vue 文件编码损坏问题（PowerShell Out-File 导致的 UTF-8 破坏）
